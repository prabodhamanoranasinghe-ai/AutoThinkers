17:T19c4,<p>If AI has made you faster at starting drafts but slower at finishing them, you need a <strong>workflow</strong>, not another tool.</p>
<p>This tutorial builds a 60-minute AI content system you can reuse for blog posts, newsletters, LinkedIn threads, and tutorials.</p>
<h2>Outcome</h2>
<p>By the end you will have:</p>
<ul>
<li>A repeatable content pipeline</li>
<li>Saved prompts for each stage</li>
<li>A quality gate before publishing</li>
<li>One finished draft from a real topic</li>
</ul>
<h2>The 6-stage pipeline</h2>
<ol>
<li>Topic lock</li>
<li>Angle &#x26; outline</li>
<li>Research assist</li>
<li>Draft</li>
<li>Human edit + fact check</li>
<li>Package for SEO/publish</li>
</ol>
<p>AI helps most in stages 2–4. You stay responsible for 1, 5, and 6.</p>
<h2>Minute 0–10: Topic lock</h2>
<p>Write these three lines before opening any AI chat:</p>
<pre><code class="language-text">Topic:
Reader:
Finished artifact:
</code></pre>
<p>Example:</p>
<pre><code class="language-text">Topic: AI image tools for YouTubers
Reader: creators who film weekly and hate thumbnail busywork
Finished artifact: a tutorial with a recommended starter tool + 5 prompts
</code></pre>
<p>No topic lock = endless generation.</p>
<h2>Minute 10–20: Angle &#x26; outline</h2>
<p><strong>Prompt</strong></p>
<pre><code class="language-text">Role: content strategist.
Turn this topic lock into 3 angles and one detailed outline.
Prefer practical tutorial structure.
Include:
- promised outcome
- steps
- tools needed
- mistakes section
Topic lock:
{{paste}}
</code></pre>
<p>Pick one angle. Delete the rest.</p>
<h2>Minute 20–30: Research assist</h2>
<p><strong>Prompt</strong></p>
<pre><code class="language-text">List the key concepts a beginner must understand for this outline.
For each concept: 1-sentence explanation + what I should verify manually.
Then list 8 search queries I should run.
Outline:
{{paste}}
</code></pre>
<p>Do a quick verification pass on anything product-specific (pricing, features, limits change constantly).</p>
<h2>Minute 30–45: Draft</h2>
<p><strong>Prompt</strong></p>
<pre><code class="language-text">Write a complete tutorial draft from this outline.
Voice: clear, specific, no hype.
Use short paragraphs and numbered steps.
Include copy-paste prompts in fenced code blocks.
Add a checklist near the end.
Do not invent product claims.
Outline + notes:
{{paste}}
</code></pre>
<p>Save the draft into your notes app immediately.</p>
<h2>Minute 45–55: Human edit gate</h2>
<p>Run this critique prompt, then edit yourself:</p>
<pre><code class="language-text">Critique this draft for a busy beginner.
Flag:
- missing prerequisites
- vague steps
- unverifiable claims
- weak ending
Return a punch list only.
Draft:
{{paste}}
</code></pre>
<p>Your non-negotiables:</p>
<ul>
<li>Every step is doable</li>
<li>Every tool claim is checked</li>
<li>The reader knows what “done” looks like</li>
</ul>
<h2>Minute 55–60: Package for publish</h2>
<p>Generate SEO extras only after the draft is solid:</p>
<pre><code class="language-text">Based on this final draft, produce:
1. SEO title options (5)
2. Meta description (150-160 chars)
3. URL slug
4. 5 tags
5. Social post (2 versions)
Draft:
{{paste}}
</code></pre>

<h2>Example: one post in one hour</h2>
<p><strong>Topic lock:</strong> “How to use Claude Projects for client work”</p>
<ol>
<li>Outline in 8 minutes</li>
<li>Research assist for Project setup caveats</li>
<li>Draft tutorial with screenshots placeholders</li>
<li>Edit for accuracy</li>
<li>Publish package: title, meta, tags</li>
</ol>
<p>That is a real AutoThinkers-style tutorial loop.</p>
<h2>Guardrails</h2>
<ul>
<li>Never paste confidential client files into consumer AI tools unless your plan and policy allow it</li>
<li>Keep a human as final editor</li>
<li>Track prompts that produce wins</li>
<li>Retire workflows that create cleanup debt</li>
</ul>
<h2>Closing checklist</h2>
<ul class="contains-task-list">
<li class="task-list-item"><input type="checkbox" disabled> Topic lock written</li>
<li class="task-list-item"><input type="checkbox" disabled> One outline chosen</li>
<li class="task-list-item"><input type="checkbox" disabled> Draft saved outside the chat</li>
<li class="task-list-item"><input type="checkbox" disabled> Claims verified</li>
<li class="task-list-item"><input type="checkbox" disabled> Meta/slug/tags prepared</li>
<li class="task-list-item"><input type="checkbox" disabled> Prompt versions filed for reuse</li>
</ul>
<p>Master this hour-long loop and AI becomes a publishing system — not a distraction engine.</p>
