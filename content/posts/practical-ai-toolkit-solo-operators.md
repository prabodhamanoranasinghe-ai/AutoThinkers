Most people do not need twenty AI apps. They need a **small toolkit** that reliably removes shallow work.

This AutoThinkers guide is for creators, founders, freelancers, and solo operators who want a practical AI stack — not a bookmark graveyard.

## The rule: one job per tool

Before installing anything, assign jobs:

| Job | Example outcome |
| --- | --- |
| Think & draft | Briefs, outlines, first drafts |
| Research assist | Summaries with sources to verify |
| Repetitive ops | Email triage, meeting notes, formatting |
| Make media | Thumbnails, diagrams, short clips |
| Build software | Code help, refactors, tests |

If two tools share the same job, keep the one you open weekly.

## The recommended starter stack

### 1. Primary reasoning model (required)

Pick **one** strong general model as your home base:

- **ChatGPT** — broad ecosystem, strong everyday drafting
- **Claude** — excellent long-document work and careful rewriting
- **Gemini** — strong when your life already lives in Google Workspace

**Tutorial setup (15 minutes):**

1. Create a Project / custom workspace named after your business
2. Upload only non-sensitive reference docs (brand voice, FAQ, offer sheet)
3. Save three reusable prompts: *Outline*, *Draft*, *Critique*
4. Turn on memory features carefully — or keep a manual “context note” you paste

### 2. Notes system that stores prompts (required)

AI without a notes home becomes chat chaos.

Use Notion, Obsidian, Apple Notes, or Google Docs — whatever you already trust.

Create four folders:

1. `Prompts`
2. `Workflows`
3. `Outputs to edit`
4. `Decisions`

### 3. Transcription + meeting cleanup (high ROI)

If you take calls, add a transcription tool (Otter, Granola, Fireflies, or built-in meeting notes).

**Workflow:**

1. Record / transcribe
2. Paste transcript into your primary model
3. Ask for: decisions, open loops, customer language, next actions
4. File the cleaned note the same day

### 4. Optional image / media tool

Add Midjourney, Ideogram, or Canva AI only if visuals are part of your offer.

Skip this layer if writing and ops are your bottleneck.

### 5. Optional automation layer

Zapier, Make, or n8n come **after** a manual workflow works twice.

Automating a broken process just creates expensive mess.

## One-afternoon setup tutorial

### Hour 1 — Choose and configure

1. Pick primary model + notes app
2. Create your workspace
3. Write a 10-line “About my work” context block

### Hour 2 — Build your first three prompts

**Outline prompt**

```text
Role: senior operator and clear writer.
Task: turn my rough notes into a structured outline.
Constraints: no fluff, keep my voice, mark assumptions.
Output: H2/H3 outline + open questions.
Notes:
{{paste}}
```

**Draft prompt**

```text
Expand this outline into a practical draft.
Audience: {{who}}
Tone: direct, specific, no hype.
Include examples and a short checklist at the end.
Outline:
{{outline}}
```

**Critique prompt**

```text
Critique this draft like a skeptical editor.
Flag: unclear claims, missing steps, weak CTA, generic advice.
Return: rewrite plan in 7 bullets, then a tighter intro.
Draft:
{{draft}}
```

### Hour 3 — Run a real task end-to-end

Pick one unfinished piece of work:

- newsletter
- landing page section
- client proposal
- SOP

Run Outline → Draft → Critique → human edit → publish/send.

If that loop works, your toolkit is already valuable.

## What to avoid in 2026

- Tool hopping every week
- Paying for five “AI writing” apps that do the same thing
- Pasting private customer data into random free tools
- Publishing unedited AI text
- Building automations before you have a checklist

## A simple monthly review

Once a month, ask:

1. Which tool did I open most?
2. Which paid tool did I ignore?
3. Which prompt produced reusable output?
4. What still needs a human judgment step?

Cancel ignored tools. Promote winning prompts into your notes system.

## Closing

A practical AI toolkit is boring on purpose: one strong model, one notes home, one transcription habit, and optional media/automation later.

Master that stack before chasing the next launch. When you are ready for the next guide, we will go deeper on prompts, workflows, and tool-by-tool tutorials.
