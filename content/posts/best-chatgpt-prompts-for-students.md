ChatGPT is useful for school only when your prompts are **specific**. Vague asks like “explain biology” create fluff. Tight prompts create quizzes, plans, and feedback you can actually study from.

This is a **copy-paste prompt library** for students — pair it with academic integrity rules from your school.

> Related deep guide: [AI for Students: How to Study Smarter…](/blog/ai-for-students-study-smarter/)

## How to use these prompts

1. Paste the prompt into ChatGPT
2. Replace `{{brackets}}`
3. Ask for a second pass: “Make this harder” or “Mark my answers”
4. Study the output — do not submit unedited AI writing as your own

## 1) Study planner prompt

```text
Role: academic coach for busy students.
Objective: build a realistic study plan.
Course: {{course}}
Exam/deadline: {{date}}
Available study time: {{hours per day}} on {{days}}
Current level: {{beginner/intermediate/struggling}}
Constraints:
- Include active recall and short breaks
- Do not schedule more than I can actually do
Output:
1. Weekly schedule table
2. Daily 45-minute session template
3. Priority topics list
4. What to cut if I fall behind
```

## 2) Lecture / notes summary prompt

```text
Role: careful study tutor.
Objective: turn my notes into a revision sheet.
Subject: {{subject}}
Notes:
{{paste notes}}
Constraints:
- Keep key terms and definitions
- Flag anything that looks incomplete
- Do not invent facts not in my notes
Output:
1. One-page summary
2. Key terms list
3. 8 practice questions
4. 3 likely exam traps
```

## 3) Explain-it-simply prompt (Feynman style)

```text
Role: patient tutor.
Objective: explain {{topic}} so I can teach it back.
My level: {{level}}
Constraints:
- Use a simple analogy
- Then a precise version
- Ask me 3 check questions at the end
Output:
Analogy → Core explanation → Common mistakes → Check questions
```

After it asks questions, answer **without looking**, then paste your answers for marking.

## 4) Practice quiz generator

```text
Role: exam coach.
Objective: generate a practice quiz on {{topic}}.
Difficulty: {{easy/medium/hard}}
Source material:
{{paste notes or textbook section summary}}
Constraints:
- Mix multiple choice and short answer
- Include an answer key separately
- Mark which questions test memorization vs application
Output:
Quiz (10 questions)
Then: Answer key + short explanations
```

## 5) Essay outline prompt (not a full ghostwritten essay)

```text
Role: writing coach.
Objective: help me outline MY essay.
Prompt/assignment: {{paste assignment}}
My thesis idea: {{your thesis}}
Evidence I already have: {{bullets}}
Constraints:
- Do not write the full essay
- Strengthen structure and argument flow
- Suggest where I need sources
Output:
1. Thesis refinement options (2)
2. Outline with H2/H3
3. Evidence gaps
4. Counterargument section
```

Use AI for structure. Write the final prose yourself unless your syllabus explicitly allows otherwise.

## 6) Weak-area drill prompt

```text
Role: tutor who targets weak spots.
I keep missing questions about: {{weak topic}}
Show what I got wrong:
{{paste mistake or confused explanation}}
Constraints:
- Diagnose the misunderstanding
- Give 5 progressive drills
- End with a mini-quiz
```

## 7) Flashcard maker prompt

```text
Role: spaced-repetition coach.
Objective: create flashcards from my notes.
Notes:
{{paste}}
Constraints:
- One fact per card
- Prefer “question → answer” format
- Avoid yes/no cards
Output:
20 flashcards in a two-column list (Front | Back)
```

## 8) Oral exam / presentation rehearsal

```text
Role: examiner.
Topic: {{topic}}
Ask me 8 questions one at a time.
After each answer I paste, score me 1–5 and tell me what was missing.
Start with question 1 only.
```

## Prompt upgrades that instantly improve results

Add these lines to almost any student prompt:

- `Do not invent citations.`
- `If information is missing, ask up to 3 clarifying questions first.`
- `Keep answers concise; prefer bullets and tables.`
- `Challenge me — do not overpraise.`

For prompt structure fundamentals, see the [Prompt Craft Tutorial](/blog/prompt-craft-tutorial-real-work/).

## Academic integrity (non-negotiable)

- Follow your institution’s AI policy
- Cite sources properly
- Use AI to **learn**, not to fake authorship
- Expect oral follow-ups in many courses — if you cannot explain it, you did not learn it

## 7-day prompt challenge

- Day 1: Study planner
- Day 2: Notes → revision sheet
- Day 3: 10-question quiz + self-mark
- Day 4: Essay outline only
- Day 5: Weak-area drills
- Day 6: Flashcards
- Day 7: Oral rehearsal

Track what improved: quiz scores, recall speed, or clarity when explaining out loud.
